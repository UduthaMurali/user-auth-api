User Authentication Service

A simple REST API for user registration, login, and JWT-based authentication — built to demonstrate Config Drift Detection in CI/CD pipelines.

👤

Register

Create a new user account with username and password

🔑

Login

Authenticate and receive a signed JWT access token

📧

Email Verify

Send verification emails via SMTP on registration

🌐

OAuth

Google login, Redis rate limiting, Stripe payments

API Endpoints

GET /health Health check
POST /auth/register Register new user
POST /auth/login Login, get JWT token
GET /auth/me Get current user
GET /auth/google Google OAuth login
DEL /auth/me Delete account
